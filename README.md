Esse aplicativo tem por objetivo ser útil e divertido para pessoas em acampamentos.
Ele possui três abas:
- Uma com uma frase motivadora aleatória de uma pequena lista que muda todo dia;
- Outra com uma garrafa, que serve para representar uma latinha, que pode ser clicada fazendo um barulho de refrigerante;
- Por fim uma tela que usa o magnetômetro para fazer uma bússola que sempre vai apontar para o Sul (Norte Magnético);

Não fiz uma latinha usando o stylesheet por eu não ser tão bom com estilização, mas caso alguém goste de fazer, sinta-se a vontade.

alguém descubra o motivo, agradeceria que me contasse para que eu pudesse resolver o problema.
